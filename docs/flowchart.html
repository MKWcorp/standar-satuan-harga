Keluaran (output) yang tersedia

  • Ekspor Excel: data usulan per instansi, data konsolidasi semua instansi, standar harga per periode.
  • Ekspor PDF berbentuk lampiran peraturan kepala daerah, kertas A4 potret, siap tanda tangan.
  • Time log tiap usulan: siapa membuat, mengajukan, mengoreksi harga, menyetujui, kapan.
  • Kolom output bisa diatur: Kode Kelompok, Barang, Spek, Satuan, Harga, Kode Rekening, TKDN, ditambah Time Stamp.

Aturan penting

  • Metode input Grid atau Form, hanya satu yang aktif.
  • Lewat tanggal tutup, periode terkunci otomatis: instansi tidak bisa input, approval tetap jalan.
  • Kembalikan dan Tolak wajib disertai catatan untuk instansi.
  • Seluruh data bisa dicadangkan dan dipindah ke hosting lain.
